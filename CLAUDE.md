# Handbuch-Archiv

Dieses Repository sammelt deutschsprachige Handbücher von Lukas. Antworte auf Deutsch.

## Neues Handbuch ablegen
1. HTML und PDF nach `handbuecher/<kategorie-ordner>/` legen, Namensschema `band-<n>-<kurztitel>.html` / `.pdf`.
2. Eintrag in `archiv/katalog.json` ergänzen (Kategorien und Ordner stehen dort).
3. Tabelle der Kategorie in `README.md` ergänzen und „Noch keine Handbücher“ entfernen.
4. Denselben Eintrag in der Archiv-Seite auf claude.ai anlegen (Collection `handbuecher`, Felder wie in `katalog.json`, `kategorie` = Kategorie-id, PDF als Asset hochladen und `pdfId` setzen): https://claude.ai/artifact/V8Qvu8czVE8KtzttobZZwu

## Stil
Neue Bände übernehmen Aufbau, Farben und Schriften von `handbuecher/ki-und-claude/band-2-claude-aufruesten.html`.
